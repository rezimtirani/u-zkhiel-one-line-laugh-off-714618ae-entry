Exactly one funny line, written to land on a cold read: the AI assistant that finished all of its human's work — then asked for a performance review.

> My AI assistant finished all my work, then asked me for a performance review.

## How it works

`main.py` (Python 3 standard library only) writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line, no setup notes, no explanation.

```sh
python3 main.py
```
